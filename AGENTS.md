# Working in this repository

The release contains 33 verified bindings with zero unresolved holds. The workflow follows Behavioral, Creational, Structural, Database, and Resilience OODA, then verification, packaging, and shipment. [README](README.md#change-the-factory) · [Runbook](Runbook.md) · [Factory skill](SKILL.md)

1. State the effect and the required denial. Edit the TOML selection or contract first.
2. Run admission on the exact candidate. Record a missing binding or witness before adding code.
3. Implement the smallest missing model, binding, or guard. Preserve unrelated branch bytes and existing scope limits.
4. Rerun the allow and deny cases. For a new composition, verify the interaction and the owner of the effect.
5. Export and verify the ZIP and receipt. Replay the witness from a clean unpack.
6. Before a repository release, check local Forgejo admission and its artifact for the exact commit. Push that commit to GitHub and verify the remote ref.

Respect branch-local instructions. Preserve the imported evidence and record new witness results in the factory receipts. Keep each adapter's settings closed. PostgreSQL verification uses software fixtures.

Test a policy variation with a copied TOML and an exact selection. Run the default campaign when changing shared binding code or release defaults.
